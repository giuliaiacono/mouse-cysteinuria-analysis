Cystinuria Mouse Gut Microbiome

Nirmal Bhatt, Malcolm Starkey

Author: Andrew Perry
BIP: BIP-1131 iLab: MBP-MS-466 starting date: 14-Aug-2023

Summary

Goal: To explore the differences between faecal microbiomes of the homozygous cystinuria mice with heterozygotes.

Data: Mouse faecal microbiome, short read shotgun WGS.

Three conditions with 5 samples each:

  • Abx (antibiotic treated)
  • Het (heterozygous)
  • Homo (homozygous)

Potential covariates:

  • all mice are male (so no sex covariate)
  • box locations (some mice were housed together in the same box)

The cystinuria includes formation of cysteine stones in the predominantly in the kidney. Stone count, mass (mg) and total stone surface area (mm^2) was also provided.

Pipeline overview

Host (Mus musculus) and PhiX reads were depleted from quality-filtered paired-end reads using Bowtie2. Taxonomic assignments of the remaining reads were made using MetaPhlAn4 against the ChocoPhlAn database (vOct22).

Analysis

Data was analysed in R, primarily using the mia and miaViz Bioconductor pacakges. Taxonomic abundance was assessed using MetaPhlAn4, with differential abundance testing via ANCOM-BC2. Functional and pathway enrichment was assessed using HUMAnN, with differential pathway abundance testing via MaAsLin2.

  • Raw read QC
    • Raw sequencing data is of good quality. ~50-80M 100bp paired reads per sample. Most samples have ~3-5% mouse host reads (removed).
  • MetaPhlAn4 taxonomy and diversity
  • HUMAnN functional and pathway enrichment
  • Summary notes & proposed manuscript figures
